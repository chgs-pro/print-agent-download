# CHGS Print Agent — загрузка

Программа для склада: печатает этикетки и документы из WMS на принтеры этого компьютера. Работает в фоне, значок —
рядом с часами.

**Скачать:** [страница загрузки](https://github.com/chgs-pro/print-agent-download/releases)

| Система | Файл |
| --- | --- |
| Windows 10/11 (64-бит) | `ChegdeskladPrintAgent-<версия>-windows-amd64-setup.exe` |
| Ubuntu 24.04+ / Debian 13 | `chegdesklad-print-agent-<версия>-amd64.deb` |

Файлы `.sig` рядом — для встроенного обновления, скачивать их не нужно.

## Что понадобится

- **Адрес API** и **токен агента** — в WMS: карточка склада → «Настройки» → «Настройка агента печати» →
  «Подключение нового агента».
- **Принтер этикеток**, установленный в системе. Принтер для документов — по желанию.

## Установка

**Windows.** Запустите установщик и нажмите «Установить» — права администратора не нужны. Если Windows покажет
«Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае».

**Ubuntu / Debian.** Установите пакет и запустите «CHGS Print Agent» из меню приложений:

```bash
sudo apt install ./chegdesklad-print-agent-<версия>-amd64.deb
```

## Настройка

В окне программы укажите адрес API, токен агента и принтер этикеток — настройки сохраняются сами. Нажмите
«Пробная этикетка», чтобы проверить печать.

Чтобы печатать из браузера автоматически, нажмите в программе «Код для браузера» и введите код в WMS: карточка
склада → «Настройки» → «Настройка агента печати» → «Подключить браузер».

## Обновления

Программа сама проверяет новые версии и предлагает обновиться кнопкой «Обновить» в окне.
